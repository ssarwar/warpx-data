Numerical source constraints for the reciprocal rotational model.

`o2_bhattacharyya.json` contains Tables II–III, potential B with cutoff 2 a0: N=1→1, N=1→3, and inclusive integrals, followed by the corresponding momentum-transfer integrals, in a0². These theoretical values do not include exchange and do not uniquely determine the higher-rank DCS.

The offline reference in WarpX Tools/CrossSections/reciprocal_rotation documents the source qualifications and the positive completion used in production. These files contain scientific inputs, not validation records.
