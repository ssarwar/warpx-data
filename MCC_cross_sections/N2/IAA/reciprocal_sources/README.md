Numerical source constraints for the reciprocal rotational model.

`n2_gote.json` contains the published transfer-rank entries; -1 denotes a <1% bound. Inconsistent rows are retained as source data and are not silently normalized into production probabilities.

`n2_jung.json` contains nonnegative transfer-rank fractions inferred from the seven-angle digitization at 2.22 and 2.47 eV. These are processed experimental constraints, not new measurements.

The offline reference in WarpX Tools/CrossSections/reciprocal_rotation documents the source qualifications and the positive completion used in production. These files contain scientific inputs, not validation records.
